# Static UI fonts

Baloo2-ExtraBold.ttf: Baloo 2, weight 800.
Nunito-ExtraBold.ttf: Nunito, weight 800.
Nunito-Bold.ttf: Nunito, weight 700.

Downloaded 2026-10-10 from the official Google Fonts CSS2 API:
https://fonts.googleapis.com/css2?family=Baloo+2:wght@800&family=Nunito:wght@700;800&display=swap

These are static TrueType instances; UiFonts derives Font.PLAIN at each role's
size without synthetic bold. SIL Open Font License files are included.
JAR resources live at /resources/fonts; IntelliJ also supports the resource
copy path /boomboomkiss/resources/fonts. No file-system font lookup is used.
